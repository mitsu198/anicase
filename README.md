# ANICASE

Первый рабочий прототип сайта с аниме-карточками и виртуальной валютой.

## Запуск
1. Установи Node.js 20+
2. В папке проекта выполни `npm install`
3. Выполни `npm run dev`
4. Открой адрес, который покажет Vite (обычно http://localhost:5173)

## Уже работает
- Главная и навигация
- Открытие трёх типов кейсов с заданными шансами
- Виртуальный баланс ANICOINS (AC)
- Инвентарь с сохранением в localStorage
- Продажа карточек за AC
- Апгрейдер с шансом 38%
- Контракты от 3 карточек
- Демонстрационный кейс-баттл с ботом
- Адаптивная мобильная версия

## Важно
Это клиентский прототип: данные хранятся в браузере и могут быть изменены пользователем. Не используй его для реальных платежей, призов или ценных активов. Перед публичным запуском перенеси баланс, генерацию выпадений и все операции с карточками на сервер, добавь базу данных, защиту от повторных запросов и журнал транзакций. Авторизация намеренно не подключена.
